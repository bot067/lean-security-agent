# Модель безопасности

- LLM не имеет доступа к сети, хосту или файловой системе
- Все команды проходят валидацию (белый список + запрещённые паттерны)
- Вывод команд обрезается до 800 символов
- Контейнер запущен от nobody, read-only, лимит памяти 2GB
- Детектор останавливает зацикливание после 3 повторов
