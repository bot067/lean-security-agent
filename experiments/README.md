# Experiments

Воспроизводимые эксперименты Lean Security Agent. Каждый каталог содержит
сырые данные, метрики и инструкцию по повтору.

## Содержание

| Каталог | Что проверяет | Ключевой результат |
|---|---|---|
| [`juice-shop-v1/`](juice-shop-v1/) | Полный цикл статического + динамического анализа OWASP Juice Shop | 2.2 с, 23 находки (5 CRITICAL / 14 HIGH / 4 MEDIUM), авто-детект AngularJS, 108/108 unit-тестов |
| [`local-inference-benchmark-rtx5060/`](local-inference-benchmark-rtx5060/) | Локальный инференс планировщика на RTX 5060 8GB | 57–60 ток/с стабильно на ctx 2048→16384, VRAM 5.84–6.22 ГБ, 51 °C |

## Формат эксперимента

- `README.md` — методика, результаты, воспроизведение.
- `*.json` — сырые данные и метрики.
- `run_experiment.sh` / `bench_*.py` — скрипт воспроизведения.

## Методология

Результаты фиксируются по принципу **EBM Level I** — воспроизводимые
инструментальные замеры на реальном железе, а не оценочные суждения моделей.
