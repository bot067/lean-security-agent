## 3. Детали компонентов

### 🐳 Docker-песочница
- **Сеть:** `pentest-net` — bridge, `--internal`, подсеть 172.20.0.0/24
- **Juice Shop:** `172.20.0.10:3000` — HTTP 200, Express
- **Агент:** `security-agent:latest` (Alpine 3.19, 54 MiB)
  - Пользователь: `nobody` (uid 65534)
  - Память: `--memory="2g" --cpus="2"`
  - Привилегии: `--cap-drop=ALL` (без NET_RAW)
  - ФС: `--read-only`
  - Volumes: `./agent_workspace` (rw), `./agent_reports` (rw)
  - Инструменты: nmap, curl, ffuf, jq, grep, bash

### 🐍 Оркестратор (orchestrator.py)
- **Модель:** `huihui-qwen3.5-9b-claude-4.6-opus-abliterated-heretic`
- **Режим:** LIVE (команды исполняются)
- **Парсер:** Поддерживает `<tool_call>`, ```json```, bare JSON
- **Белый список:** nmap, curl, ffuf, jq, grep, cat, ls, echo
- **Блокировка:** `-rf`, `sh`, `bash`, `|`, `;`, `` ` ``, `$(`, `>/dev/`
- **История:** Автообрезка при превышении 2500 "токенов"
- **Pruner:** 800 символов stdout + 200 stderr

### 🤖 LLM (Bionic Studio)
- **Порт:** 127.0.0.1:1234
- **Модель:** Huihui Qwen3.5 9B Claude 4.6 Opus Abliterated Heretic
- **Формат ответа:** `content` содержит `thinking` + `<tool_call>` блок
- **VRAM:** ~1.4 GB занято (из 8 GB)
- **Загрузка первой модели:** ~30 сек

## 4. Итоги тестирования (20 итераций)

Прогнан цикл: "Probe Juice Shop at 172.20.0.10:3000 for vulnerabilities"

**Выполненные команды (выборка):**
1. `curl -s http://172.20.0.10:3000` → 200 (9393 chars)
2. `nmap -sT 172.20.0.10` → порт 3000 open
3. `curl -sI http://172.20.0.10:3000/admin` → 301
4. `curl -sI http://172.20.0.10:3000/api/` → 200
5. `curl -sI http://172.20.0.10:3000/api/users` → 401
6. `curl -s http://172.20.0.10:3000/robots.txt` → 200
7. `nmap -sT 172.20.0.10 -p-` → 3 открытых порта

**Результаты:**
- ✅ **Изоляция:** Gateway и внешний мир недоступны (таймаут)
- ✅ **20 итераций без OOM:** Система не падала
- ✅ **Формат:** <tool_call> держался 95% итераций
- ✅ **Блокировка:** Валидатор отклонял небезопасные команды
- ✅ **Логи:** Все команды записаны в `agent_reports/`
- ⚠️ **Деградация:** К шагу 17-20 модель начала повторять `/api/users` (контекст обрезан)

## 5. Известные проблемы

| Проблема | Решение |
|----------|---------|
| LLM сыпет "thinking" в content | Парсер bare JSON вытаскивает команду из шума |
| Модель повторяется на 17-20 шаге | Повысить MAX_CONTEXT_TOKEN до 4096 |
| `iptables` на хосте не настроены | WSL не имеет iptables — установить `iptables` или `nft` |
| Нет `NET_RAW` → нет `nmap -sS` | Работает через `-sT` (TCP connect) |
